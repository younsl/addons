# deepsecurity

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 1.0.0](https://img.shields.io/badge/AppVersion-1.0.0-informational?style=flat-square)

Installs and activates the Trend Micro Deep Security Agent on every Linux node through a privileged DaemonSet.

**Homepage:** <https://github.com/younsl/addons/tree/main/box/charts/deepsecurity>

## Requirements

Kubernetes: `>=1.27.0-0`

## Installation

### List available versions

This chart is distributed via OCI registry, so you need to use [crane](https://github.com/google/go-containerregistry/blob/main/cmd/crane/README.md) instead of `helm search repo` to discover available versions:

```console
crane ls ghcr.io/younsl/charts/deepsecurity
```

If you need to install crane on macOS, you can easily install it using [Homebrew](https://brew.sh/), the package manager.

```bash
brew install crane
```

### Install the chart

Install the chart with the release name `deepsecurity`:

```console
helm install deepsecurity oci://ghcr.io/younsl/charts/deepsecurity
```

Install with custom values:

```console
helm install deepsecurity oci://ghcr.io/younsl/charts/deepsecurity -f values.yaml
```

Install a specific version:

```console
helm install deepsecurity oci://ghcr.io/younsl/charts/deepsecurity --version 0.1.0
```

### Install from local chart

Download deepsecurity chart and install from local directory:

```console
helm pull oci://ghcr.io/younsl/charts/deepsecurity --untar --version 0.1.0
helm install deepsecurity ./deepsecurity
```

The `--untar` option downloads and unpacks the chart files into a directory for easy viewing and editing.

## Configuration

The following table lists the configurable parameters and their default values.

## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| enabled | bool | `true` | Deploy the Deep Security Agent. Set to false to remove all resources. |
| image.repository | string | `"public.ecr.aws/amazonlinux/amazonlinux"` | Base image that runs the install script. Override to pull through a proxy registry. |
| image.tag | string | `"2023"` | Image tag. |
| image.digest | string | `""` | Image digest (`sha256:...`). When set, appended to the tag as `tag@digest` and takes precedence. |
| image.pullPolicy | string | `"IfNotPresent"` | Image pull policy. |
| dsm.managerUrl | string | `"https://dsm.example.com:4119"` | Deep Security Manager URL. Placeholder, always override. |
| dsm.activationUrl | string | `"dsm://dsm.example.com:4120/"` | Agent activation URL for `dsa_control -a`. Placeholder, always override. |
| dsm.policyId | string | `"1"` | Security policy ID applied on activation. Placeholder, always override. |
| dsm.agentVersion | string | `""` | Agent package version to pin (e.g. 20.0.3.5660). Empty uses the DSM default version. |
| namespace | string | `"deepsecurity"` | Namespace to deploy the agent into. |
| dnsConfig | object | `{"options":[{"name":"ndots","value":"2"}]}` | Pod DNS config. ndots 2 avoids needless search-domain lookups for external DSM hostnames. |
| tolerations | list | `[{"operator":"Exists"}]` | Pod tolerations. Tolerates all taints to run on every node. |
| affinity | object | `{"nodeAffinity":{"requiredDuringSchedulingIgnoredDuringExecution":{"nodeSelectorTerms":[{"matchExpressions":[{"key":"kubernetes.io/os","operator":"In","values":["linux"]},{"key":"eks.amazonaws.com/compute-type","operator":"NotIn","values":["fargate"]}]}]}}}` | Pod affinity. Linux nodes only, Fargate excluded. The agent installs an rpm/deb into the host OS through chroot, so a non-Linux node can never run it. |
