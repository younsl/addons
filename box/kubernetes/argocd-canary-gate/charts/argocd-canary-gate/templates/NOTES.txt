  kubectl -n {{ .Values.canaryGate.argocd.namespace }} describe application <app>

To bypass the gate for one Application:

  kubectl -n {{ .Values.canaryGate.argocd.namespace }} annotate application <app> \
    {{ .Values.canaryGate.exempt.annotation }}=true

The UI tile is optional and the gate enforces without it. To render the verdict
in the Argo CD status panel, register the proxy extension in argocd-cm under
the name {{ .Values.uiExtension.name }} and deliver the script with an
argocd-extension-installer init container pointed at
/api/v1/extension.tar on this service. See the chart README.
