15 · right-sizing

실측 위에 request 와 limit 을 다시 놓았다

회색 전 · 노랑 후 · 흰색 실측. CPU 행은 0~4400m 축, 메모리 행은 0~2200Mi 축. limit 은 page cache 상한만 남는다. CPU 는 limit 이 없어 순간 4.13 core 까지 올라간다. 1Gi 까지 내리면 SQLite hot page 가 반복 회수되어 I/O 가 는다.
