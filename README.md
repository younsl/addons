# o

![UNIX](./docs/assets/unix-86.jpg)

> Photo: [Nokia Bell Labs](https://www.nokia.com/bell-labs/), UNIX 86.

A [monorepo](./docs/monorepo.md) of [Observability](https://opentelemetry.io/docs/concepts/observability-primer/) and [Kubernetes](https://github.com/kubernetes/kubernetes) operation addons. [Go](https://github.com/golang/go) [1.27.0](https://github.com/golang/go/releases/tag/go1.27.0) is the primary runtime, with [Rust](https://github.com/rust-lang/rust) [1.98+](https://github.com/rust-lang/rust/releases/tag/1.98.0) used for the CLI tools and several addons. Includes CLI [tools](./box/tools/), [kubernetes](./box/kubernetes/) addons, [kubernetes operators](https://kubernetes.io/docs/concepts/extend-kubernetes/operator/), runtime images, and [docs](./docs/).
